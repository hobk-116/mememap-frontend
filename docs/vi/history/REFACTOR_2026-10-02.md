## Refactor nền tảng — 02/10/2026

Đã thực hiện sáu bước theo thứ tự trước khi xây dựng community:

| Bước | Kết quả |
| --- | --- |
| 1. Chuẩn hóa kiểm tra hồi quy | Sửa giả định cũ về Menu/Admin và hình học ghim; tạo runner browser với dữ liệu tạm riêng cho từng nhóm. |
| 2. Tách nghiệp vụ backend | `server.py` xử lý HTTP; `mememap/` chứa service tài khoản, hồ sơ, ghim và kiểm duyệt. `Application` hỗ trợ test trực tiếp và instance độc lập. |
| 3. Migration, cấu hình và ảnh | Migration có phiên bản, rollback schema, sao chép ảnh trước commit; cấu hình database/uploads/cookie theo môi trường; kiểm tra dọn ảnh và giữ dữ liệu khi lỗi. |
| 4. API client dùng chung | Trang chính, map và Admin cùng dùng `api.js`; lỗi giữ mã/status/chi tiết, xử lý phiên hết hạn và hủy yêu cầu nhất quán. |
| 5. Tách các phần của map | Các module pins, composer, profile, leaderboard và bản dịch riêng; `map.js` ghép các thành phần với layout hiện có. |
| 6. Thống kê và phạm vi địa lý | Hồ sơ dùng tổng từ database, độc lập feed đã tải. `regions.py` cấp cấu hình cho map và kiểm tra phạm vi đăng ghim ở backend. |

Giữ bản đồ yêu cầu đăng nhập, đăng xuất chỉ từ icon hồ sơ của bản thân và có xác nhận, Menu/Admin dùng chung bảng mobile và độc lập trên desktop. Các route và dữ liệu sản phẩm hiện có được giữ; thêm `GET /api/map-config` và bảng `schema_migrations`.

Chưa triển khai membership, local/guest, ranh giới polygon, lọc feed theo vùng hoặc app native. Nền tảng giữ tách biệt trường và phường nơi sống cho community tương lai; không mặc định membership của trường suy ra membership phường. Leaflet và dịch vụ tile không đổi.

Chạy backend, API client và toàn bộ browser theo [hướng dẫn vận hành](../TESTING.md#chạy-toàn-bộ-kiểm-tra-nền-tảng). Dữ liệu kiểm tra nằm trong thư mục tạm; cần khởi động lại server đang dùng để nhận code backend mới.

Kết quả kiểm tra ngày 02/10/2026: 22 kiểm tra Python đạt, nhóm API client đạt, cả 6 nhóm browser đạt sau khi sửa cách test chờ hộp thoại đăng xuất lỗi. Các nhóm browser gồm giao diện chung, ghim tương tác, Admin, bảng mobile, hợp đồng nền tảng và đăng xuất. Kiểm tra cú pháp toàn bộ JavaScript và ví dụ JSON cấu hình cũng đạt. Trình duyệt sử dụng Chrome/Chromium với viewport desktop/mobile; chưa kiểm tra trên thiết bị iOS/Android thật.

## Ghi chép đợt refactor giao diện trước đó

Đợt sửa này tập trung vào các luồng đã phải chỉnh nhiều lần trong quá trình phát triển. Các API, database và tính năng sản phẩm hiện có được giữ; không thêm tính năng cộng đồng, báo cáo hoặc đăng nhập mới.

## Thay đổi chính

- Tách CSS và JavaScript khỏi hai trang HTML. Typography, animation popup và thành phần profile dùng chung trong `assets/`.
- Gom trạng thái menu/admin, chiều cao bảng mobile và vị trí nhóm nút vào một bộ quản lý trong `assets/js/map-layout.js`.
- Tính vị trí map từ tọa độ neo tuyệt đối, thay cho các bước pan làm tròn cộng dồn. Kéo bảng sử dụng khoảng dịch chuyển từ điểm bắt đầu chạm, tránh rìa bảng nhảy tới ngón tay.
- Dùng cùng vòng cập nhật cho nhóm nút, ghim và map khi thay đổi bố cục. Đổi menu/admin giữ cùng hình học; resize tính lại tâm vùng bản đồ đang thấy.
- Giữ presentation của profile riêng trong suốt fade-out. Kết quả tải profile đến muộn không ghi đè một profile khác vừa mở hoặc mở lại bảng đã đóng.
- Tái sử dụng marker Leaflet khi làm mới ghim, giữ popup đang mở và dùng một bộ xử lý sự kiện cho nội dung popup.
- Chờ xử lý ảnh trước khi gửi ghim. Việc chọn ảnh mới vô hiệu hóa kết quả xử lý ảnh cũ, tránh gửi nhầm ảnh.
- Hai trang dùng cùng bộ xử lý ảnh, chuyển WebP và fallback PNG cho Safari. Backend dùng cùng hàm kiểm tra/chuyển ảnh cho meme và avatar.
- Đóng kết nối SQLite sau mỗi lần sử dụng; xử lý đổi avatar trong transaction và lấy đúng đường dẫn ảnh trước đó để dọn file.
- Asset server phục vụ rõ từng file CSS/JS và icon. Mỗi phản hồi có một chính sách cache; frontend asset được kiểm tra lại khi reload.

## Kiểm tra backend

Chạy từ thư mục repo, với `cwebp` có trong `PATH`:

```sh
python3 -m unittest discover -s tests -v
```

Các nhóm kiểm tra bao gồm asset và quyền truy cập, đăng nhập/profile/avatar/logout, tạo ghim/vote/Memerboard/xóa admin, xác thực ảnh và đóng kết nối SQLite. Database và uploads được tạo trong thư mục tạm, không dùng dữ liệu đang chạy của MemeMap.

## Kiểm tra trình duyệt

`tests/check_browser.cjs` cần Node.js, Playwright và Chromium có sẵn. Playwright là công cụ kiểm tra, không phải dependency chạy website.

Khởi động server dữ liệu tạm trong terminal thứ nhất:

```sh
python3 tests/serve_fixture.py
```

Trong terminal thứ hai, dùng URL localhost mà server vừa in:

```sh
node tests/check_browser.cjs http://127.0.0.1:PORT
```

Nếu dùng Chrome đã cài trên macOS, có thể đặt biến `MEMEMAP_TEST_BROWSER` thành đường dẫn binary Chrome. Nếu Playwright nằm ngoài thư mục repo, đặt `NODE_PATH` thành thư mục `node_modules` tương ứng.

Các kiểm tra trình duyệt bao gồm tiêu đề trang sau đăng nhập, vị trí và fade-out của profile, kết quả tải profile đến muộn, đổi menu/admin, ghim cố định, giữ marker qua chu kỳ refresh, resize, kéo bảng nhiều vòng không trôi sang đông, vị trí nút mobile, fallback khi canvas không xuất được WebP và gửi ảnh ngay sau khi chọn. Test chặn yêu cầu tile công cộng để không tạo lưu lượng bản đồ khi kiểm tra.

Đã chạy trên Chromium với viewport desktop/mobile. Fallback ảnh được mô phỏng trong Chromium; việc này không thay thế kiểm tra trực tiếp Safari và thao tác chạm trên iPhone.

Sau khi kiểm tra, dừng server dữ liệu tạm bằng `Ctrl+C` để dọn thư mục tạm. Khởi động lại server MemeMap đang dùng để nhận phần backend và asset routing mới.
