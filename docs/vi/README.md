[AGENTS.md](../../AGENTS.md) là nguồn chính sách kiểm tra có hiệu lực; hướng dẫn tiếng Việt là bản dịch. Kết quả kiểm tra lịch sử không xác minh thay đổi về sau. Các bản mã nguồn trong `archive/` không sao lưu SQLite hoặc ảnh người dùng tải lên.
