# Các bản mã nguồn được lưu trữ

[English](README.md) · **Tiếng Việt** · [Tài liệu hiện tại](../docs/vi/README.md)

Lưu trữ ngày 03/10/2026 trong đợt sắp xếp tài liệu. Thư mục giữ các file mã nguồn trước đó để tham khảo; đây không phải sao lưu dữ liệu đang chạy và không được ứng dụng phục vụ.

| File | Vị trí gốc | Mục đích |
| --- | --- | --- |
| [STICKY_NOTE.md](STICKY_NOTE.md) | Thư mục gốc repo | Ghi chú ba mục gốc, giữ nguyên nội dung. Ý nghĩa hiện tại được tổng hợp ở cuối [recommendations](../docs/vi/RECOMMENDATIONS.md#sticky-note--tổng-hợp-từ-cuộc-trò-chuyện). Có [bản dịch tiếng Việt](STICKY_NOTE.vi.md) riêng. |
| [index_old.html](index_old.html) | `assets/index_old.html` | Trang HTML lịch sử gốc, giữ nguyên nội dung. Trang đang dùng vẫn là `index.html` và `landing.html` ở thư mục gốc. |

Cập nhật ưu tiên sản phẩm hiện tại trong recommendations. HTML lưu trữ có thể thể hiện hành vi và tài nguyên ngoài cũ; nó không quy định API hoặc yêu cầu sản phẩm hiện tại.
